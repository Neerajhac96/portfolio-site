EmailJS Setup Guide

To make the contact form send real emails to your inbox, follow these steps:

  1. Sign up for free at emailjs.com
  2. Connect your Gmail or Outlook under Email Services
  3. Create an Email Template using variables: {{from_name}}, {{from_email}}, {{subject}}, {{message}}
  4. Copy your Public Key from Account → API Keys
  5. In js/script.js, find the EmailJS section and replace the IDs + uncomment the send call
  6. Add the EmailJS CDN script tag to index.html before the closing </body>
